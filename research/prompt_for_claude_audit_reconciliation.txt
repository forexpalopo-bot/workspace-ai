5. VERIFIKASI ZERO LOOK-AHEAD BIAS & ZERO REPAINTING
================================================================================
Kami mengaudit kode MQL4 baris 1575-1585 pada `BioOnePro_v94_FailClosed.mq4`:
```mql4
double maVal1 = iMA(Symbol(), MA_Filter_Timeframe, MA_Filter_Period, 0, MA_Filter_Method, PRICE_CLOSE, 1);
double maVal2 = iMA(Symbol(), MA_Filter_Timeframe, MA_Filter_Period, 0, MA_Filter_Method, PRICE_CLOSE, 2);
double maSlope = maVal1 - maVal2;

if (orderType == OP_BUY  && Close[1] < maVal1 && maSlope < 0.0) return(false);
if (orderType == OP_SELL && Close[1] > maVal1 && maSlope > 0.0) return(false);
```
Semua kalkulasi menggunakan bar index 1 dan index 2 (`shift 1`, `shift 2`) serta `Close[1]`, yakni bar H1 yang sudah berstatus CLOSED (selesai terbentuk penuh). Tidak ada pembacaan bar 0 (open bar). Dijamin 100% bebas repaint dan nol look-ahead bias baik di backtest maupun live.
