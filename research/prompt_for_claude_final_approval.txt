3. AUDIT MEKANISME DST (DAYLIGHT SAVING TIME) LIVE
================================================================================
Kami telah memverifikasi implementasi kode `RuleShiftSeconds()` pada `ea/BioOnePro_v94_FailClosed.mq4` baris 2384-2390:
```mql4
int diff = (int)(TimeCurrent() - TimeGMT());
sShift = (int)MathRound(diff / 3600.0) * 3600;
```
- Sistem ini **TIDAK menggunakan offset statis** dan tidak berasumsi pada kalender DST Eropa.
- MQL4 membaca langsung selisih aktual antara jam server (`TimeCurrent()`) dan jam GMT global (`TimeGMT()`) yang di-update setiap jam.
- Selama jeda DST AS vs Eropa (25 Okt – 1 Nov), server IC Markets (yang mengikuti DST AS) akan otomatis terbaca selisihnya terhadap GMT secara real-time.
- Dalam protokol Fase 0, log audit akan mencatat 3 data waktu per trade: `TimeCurrent()`, `TimeGMT()`, dan `RuleTime()` untuk memverifikasi akurasi 0 menit penutupan Jumat 19:00 GMT.
