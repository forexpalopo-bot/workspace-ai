1. PERBAIKAN TIMEFRAME CLOSE: iClose(Symbol(), MA_Filter_Timeframe, 1)
================================================================================
Koreksi Anda mengenai `Close[1]` vs H1 timeframe sangat tepat: karena chart tester berjalan di M1, `Close[1]` sebelumnya membaca close bar M1.
Kami telah memperbaikinya pada `BioOnePro_v94_FailClosed.mq4` baris 1579:
```mql4
double maVal1 = iMA(Symbol(), MA_Filter_Timeframe, MA_Filter_Period, 0, MA_Filter_Method, PRICE_CLOSE, 1);
double maVal2 = iMA(Symbol(), MA_Filter_Timeframe, MA_Filter_Period, 0, MA_Filter_Method, PRICE_CLOSE, 2);
double maSlope = maVal1 - maVal2;
double h1Close = iClose(Symbol(), MA_Filter_Timeframe, 1);

if (!MA_Filter_Invert_Veto)
{
    if (orderType == OP_BUY  && h1Close < maVal1 && maSlope < 0.0) return(false);
    if (orderType == OP_SELL && h1Close > maVal1 && maSlope > 0.0) return(false);
}
```
